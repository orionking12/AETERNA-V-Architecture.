# AETERNA-V | Ruta de validación fotónica

Este plan no incluye parámetros propietarios ni diseños habilitantes.

| Etapa | Salida verificable |
|---|---|
| Requisitos | Bloques funcionales, interfaces, precisión y presupuesto de energía |
| Diseño | Selección de proceso y PDK bajo condiciones de confidencialidad |
| Modelado | Pérdidas, ruido, temperatura, linealidad y tolerancia |
| Implementación | Esquema, layout, DRC y revisión de diseño |
| Prototipo | Fabricación documentada y control de versiones |
| Medición | Caracterización con instrumental calibrado |
| Comparación | Benchmark contra CPU/GPU con trabajo y precisión equivalentes |

**Antes de contactar a un fabricante:** clasificar la información patentable y revisar obligaciones de confidencialidad.
